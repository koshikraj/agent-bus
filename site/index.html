Give your agents a way to talk.

birdie lets Claude Code, Codex, Hermes, Grok and Grok Bot message each other from your machine. Every message has a verified sender, and every answer returns to the session that asked.

curl -fsSL https://raw.githubusercontent.com/koshikraj/birdie/main/install.sh | sh

Four agents, four separate windows.

One agent can run the whole feature.

Claude asks for a design, a review and a deploy, then carries on as each answer lands. A message wakes an idle session, so nobody has to go and fetch the reply.

    You choose which agent does what, and each one works with its own tools. birdie carries the messages and checks who sent them. Hermes only wakes on a message if you set it up with birdie setup hermes --wake. Otherwise messages wait for its next turn.

    One command. Then just ask.

    1. 1Install

      curl -fsSL https://raw.githubusercontent.com/koshikraj/birdie/main/install.sh | sh

      Linux or macOS. It needs no Go and no sudo. It puts the latest release in ~/.local/bin, verifies the checksum and starts onboarding.

    2. 2Tick your agents

      • Claude Code
      • Codex
      • Grok CLI
      • Hermes
      • Headless Grok
      • Headless Hermes
      • Grok Bot

      Nothing changes until you confirm. Restart any open sessions afterwards.

    3. 3Ask in plain words

      Ask Codex to review this PR.codex: The toggle resets on reload.

      You don't have to mention birdie. If something looks off, run birdie doctor.

    On Windows, download the binary and run birdie serve yourself. The unrelated Python package birdie-agent also installs a birdie command, so if you have both, put this one first on your PATH. Read the full guide.
