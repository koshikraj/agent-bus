Dot and Dash as still scenes, for places that can't run the `Birds` component. They use the light-theme colors, so place them on `brand-butter`, `brand-mint` or white.

- `birds-ask.svg`: Dot pushes a letter toward Dash.
- `birds-idle.svg`: the letter reaches Dash, asleep.
- `birds-reply.svg`: Dash pushes the answer back.
- `dot.svg` and `dash.svg`: each bird alone on the wire.
