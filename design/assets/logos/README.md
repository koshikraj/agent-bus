The birdie marks and icons, for places that can't run the `Logo` component.

- `birdie-mark.svg`: full color, for light grounds. The ink is `#0A2E2B`.
- `birdie-mark-on-dark.svg`: full color, for dark grounds. Dash is `#4FD1C5` and the wire is white.
- `birdie-mark-mono.svg`: one ink, `#0A2E2B`, with white details. For light grounds.
- `birdie-app-icon.svg`: the 72px icon on its mint tile.
- `birdie-icon-small.svg`: the 24px icon. The dot and dash, on a mint tile.
- `birdie-favicon-mono.svg`: the 16px favicon, in one ink, `#0A2E2B`.

The wordmark isn't in these files. Set "birdie" in Bricolage Grotesque 800, or use the `Logo` lockup.
