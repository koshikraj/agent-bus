The envelope that stands for one message. Use it for unread counts and anywhere a message needs a symbol.

**You provide:** a `tone`, a `size` in pixels, and a `label` if the letter carries meaning by itself.

- `request` has Dot's tomato fold, for a message going out.
- `reply` has Dash's teal fold, for an answer coming back.
- `solid` matches the logo. Use it in brand contexts, not message states.
- Don't rely on the fold color alone to say which way a message is going. Pair it with text or motion.
