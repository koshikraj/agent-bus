The birdie logo as a lockup, a mark or an app icon. Use it wherever the product is named visually.

**You provide:** `variant`, and a `size` in pixels. Nothing else is needed. The colors follow the theme.

- Use `lockup` in headers and `mark` where the name is already visible.
- `icon` adapts to its size: full detail from 56px, a simplified mark from 32px, and a dot and dash below that.
- Use `mono` where only one ink is available.
- Don't recolor the birds, flip them, or remove the letter from a mark at 32px or larger.
- For places that can't run components, such as favicons, use the files in `assets/logos/`.
